A single-line cat joke with a concrete 3 a.m. setup: the cat walks across the keyboard, types a row of m's, and hits send to the boss. The twist is HR asking for the meeting notes — and the narrator admitting the cat's draft made more sense than their own.

## Run

```sh
python3 main.py
```

Writes the single joke line to `/output/entry.txt`.
